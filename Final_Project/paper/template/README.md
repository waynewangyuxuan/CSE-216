# ACM template

`acmart.cls` v2.21 (2026/11/01) and `ACM-Reference-Format.bst`, from CTAN `macros/latex/contrib/acmart.zip`, the source ACM's template page points to. License: LPPL. `acmart.cls` was generated from `acmart.dtx` with the `class` option, because the CTAN zip ships source only.

Use `\documentclass[manuscript,screen]{acmart}` for the single-column format.
